# LOOK AWAY (рабочее название)

Браузерный PS2-хоррор, управляемый глазами через вебку.
Взгляд = фонарик = враги замирают. Моргание = темнота. Выход виден только периферийным зрением.

## Где что
- `docs/GDD.md` — механики, враги, структура. Источник правды по геймплею.
- `docs/TECH.md` — архитектура, трекинг, рендер, аудио.
- `docs/ROADMAP.md` — майлстоуны, чеклисты приёмки, стартовые промпты.
- `docs/LOG.md` — журнал сессий.

Перед задачей читай только релевантный раздел, а не весь `docs/`.

## Stack
Vite + TypeScript (strict) + three.js + `@mediapipe/tasks-vision` (FaceLandmarker). Тесты: Vitest. UI без фреймворков.
Команды: `npm run dev` / `npm test` / `npm run build`. Если они поменяются, обнови этот список.

## Жёсткие правила
1. **Граница EyeState.** Игра, рендер и аудио читают только `EyeState` (`src/input/types.ts`). MediaPipe импортируется только в `src/input/tracker.ts`.
2. **Fallback обязателен.** Любая фича работает без камеры: мышь = взгляд, `Space` = моргание, удержание `C` = закрытые глаза. У тебя нет доступа к камере, поэтому проверяй через fallback и записанные фикстуры (`tests/fixtures/*.json`).
3. **Видео не покидает устройство.** Никаких загрузок кадров, логов с пикселями, аналитики по видео.
4. **Все пороги в `src/config.ts`.** Blink, зоны, скорости врагов, сухость — не хардкодить по месту.
5. **План перед кодом:** 3–7 строк — какие файлы трогаешь и как проверишь. Потом код.
6. **Хирургические правки.** Не рефакторить, не переименовывать и не переформатировать то, о чём не просили.
7. **Новые зависимости** — только с явного согласия.
8. **Закрытие майлстоуна:** пройден чеклист из `ROADMAP.md`, пункты отмечены `[x]`, в `docs/LOG.md` дописаны 1–3 строки: что сделано, что сломано, что дальше.

## Грабли
- Имена Left/Right в blendshapes и зеркалирование видео проверять эмпирически в debug-оверлее, а не угадывать.
- В тёмной комнате трекинг деградирует. `confidence` ниже порога → пауза «сигнал потерян». Никогда не трактовать это как «глаза закрыты».
- Трекер и рендер делят кадр. При просадке fps сначала снижай частоту трекинга, потом внутреннее разрешение рендера.
