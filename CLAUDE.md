# LOOK AWAY (рабочее название)

Браузерный PS2-хоррор, управляемый глазами через вебку.
Взгляд = фонарик = враги замирают. Моргание = темнота. Выход виден только периферийным зрением.

## Где что
- `docs/GDD.md` — механики, враги, структура. Источник правды по геймплею.
- `docs/TECH.md` — архитектура, трекинг, рендер, аудио.
- `docs/ROADMAP.md` — майлстоуны, чеклисты приёмки, стартовые промпты.
- `docs/LOG.md` — журнал сессий.

Перед задачей читай только релевантный раздел, а не весь `docs/`.

## Stack
Vite + TypeScript (strict) + three.js + `@mediapipe/tasks-vision` (FaceLandmarker). Тесты: Vitest. UI без фреймворков.
Команды: `npm run dev` / `npm test` / `npm run typecheck` / `npm run build`. По умолчанию открывается игра (грейбокс), `?m0` — площадка трекинга M0. `npm run setup` кладёт wasm и модель MediaPipe в `public/mediapipe/` (не в git; `dev` и `build` вызывают его сами). Если команды поменяются, обнови этот список.
Целевой браузер — десктопный Chrome/Edge. Firefox и Safari — best effort.

## Жёсткие правила
1. **Граница EyeState.** Игра, рендер и аудио читают только `EyeState` (`src/input/types.ts`). MediaPipe импортируется только в `src/input/tracker.ts`. Исключение одно: `FaceFrame` (landmarks) читают только `render/lidarEyes.ts` и `debug/`, и только для картинки. Игровая логика от `FaceFrame` не зависит.
2. **Fallback обязателен.** Любая фича работает без камеры: мышь = взгляд, `Space` = моргание, удержание `C` = закрытые глаза, удержание `L` = потеря сигнала; глаза моргают и сами (`fallback.autoBlinkPerMin`). У тебя нет доступа к камере, поэтому проверяй через fallback, синтетику (`tests/synthetic.ts`) и записанные фикстуры (`tests/fixtures/*.json`).
3. **Видео не покидает устройство.** Никаких загрузок кадров, логов с пикселями, аналитики по видео. Фикстуры содержат только числовые сигналы (blendshapes, углы головы, яркость) — без landmarks и кадров.
4. **Все пороги в `src/config.ts`.** Blink, зоны, скорости врагов, сухость, критерии приёмки — не хардкодить по месту. Меняешь баланс (`config.game`) — прогони `tests/balance.test.ts`. Персональные значения живут в `CalibrationProfile`, не в config.
5. **План перед кодом:** 3–7 строк — какие файлы трогаешь и как проверишь. Потом код.
6. **Хирургические правки.** Не рефакторить, не переименовывать и не переформатировать то, о чём не просили.
7. **Новые зависимости** — только с явного согласия.
8. **Закрытие майлстоуна:** пройден чеклист из `ROADMAP.md`, пункты отмечены `[x]`, в `docs/LOG.md` дописаны 1–3 строки: что сделано, что сломано, что дальше.

## Грабли
- Имена Left/Right в blendshapes и зеркалирование видео проверять эмпирически в debug-оверлее, а не угадывать. Знак gaze снимает калибровка, для wink есть `config.lid.swapLR`.
- Раскладка матрицы `facialTransformationMatrixes` (row/column-major) в типах MediaPipe не задокументирована. Поворот головы берём из landmarks (`tracker.ts`), не из матрицы.
- В MediaPipe нет confidence лица в результате. Наш `confidence` = наличие лица × яркость лица. В тёмной комнате трекинг деградирует: `confidence` ниже порога → пауза «сигнал потерян». Никогда не трактовать это как «глаза закрыты».
- Клавиши — только через `event.code` (`KeyC`, `Space`, `Backquote`), не `event.key`: на русской раскладке `C` это «с», а `` ` `` это «ё».
- Латентность трекинга ~кадр + инференс. Всё, что директор меняет на моргании, коммитится в первом тике после `blinkStart`, не позже (TECH → Латентность).
- Трекер и рендер делят кадр. При просадке fps сначала снижай частоту трекинга, потом внутреннее разрешение рендера.
- Хостинг в iframe (itch.io и т.п.) требует `allow="camera"` у iframe. Поддерживает ли это конкретная площадка — проверить до M7, не предполагать.
- Обновил `@mediapipe/tasks-vision` или модель — подними `CACHE` в `public/sw.js`, иначе у игроков одну загрузку поживут старые файлы.

## Деплой
Статика на Vercel, сервера нет: трекинг и игра целиком в браузере. `main` → production автоматически, PR → preview. CI (`.github/workflows/ci.yml`) гоняет typecheck, тесты и build на каждый PR. Работа идёт в ветках → PR в `main` → мерж после зелёного CI.
