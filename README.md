# LOOK AWAY

Браузерный хоррор, где контроллер — твои глаза (вебка). Смотришь — светишь, моргаешь — они идут.

**Играть:** https://lookaway-rho.vercel.app — десктопный Chrome/Edge, вебка, лучше в наушниках.
Всё работает в браузере: видео никуда не отправляется, сервера нет. После первого захода игра грузится мгновенно и работает офлайн.

Без камеры: «Мышь и клавиатура» — мышь = взгляд, `Space` = моргнуть, держать `C` = закрыть глаза.

## Локально
```
npm install
npm run dev        # http://localhost:5173, ?m0 — площадка трекинга
npm test
```
